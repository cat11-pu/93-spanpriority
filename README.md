# spanpriority

浏览器单页工作台（原生 ES 模块，零依赖）。

## 起服务看页面

    python3 -m http.server 8000

浏览器打开 http://127.0.0.1:8000/ ，改样例点运行看结果。

## 规则

- 被更高优先级区间完整包含的区间算被盖住（covered），不再绘制；
- 与更高优先级区间部分相交（互不完全包含）的区间被压下去，不算胜出（winners）；
- 重叠对数 = 有交集但不构成完全包含的区间对数；
- 绘制顺序按 (优先级升, 起点升) 排列，超过预算的按优先级从低到高丢弃；
- 区间起点不小于终点时报 E_BAD_SPAN。
